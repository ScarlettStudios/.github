## Current Projects

### PlaneToPBR — Blender Extension

Generate a **fully textured PBR plane from a single image** inside Blender.

PlaneToPBR currently generates:

- Diffuse
- Normal
- Roughness
- Depth
- Segmentation mask

Recent progress:

- Proper Blender extension refactor
- UI panel and client integration
- Unit tests and release packaging
- Ongoing hosted backend integration

→ Built for **Blender 4.2+**

🔗 https://github.com/ScarlettStudios/PlaneToPBR
