## Projects

### PlaneToPBR — Blender Extension

Generate a **fully textured PBR plane from a single image in one click.**

PlaneToPBR automatically generates:

- Diffuse  
- Normal  
- Roughness  
- Depth  
- Segmentation mask  

→ Built for **Blender 4.2+**

🔗 https://github.com/ScarlettStudios/PlaneToPBR

## Upcoming Tools

### PlaneToPBR Pro (GPU Generation)

A high-quality version of PlaneToPBR powered by **GPU inference**.

This version will run multiple advanced models together to generate:

- Higher fidelity normal maps  
- Improved depth maps  
- Better segmentation masks  
- Higher quality PBR outputs  

The service will be hosted on **GPU infrastructure** to allow fast generation through an API and web interface.

---

### PlaneToPBR — Unreal Engine Plugin

An Unreal Engine plugin that brings the PlaneToPBR workflow directly into **Unreal Engine**.

Artists will be able to:

- Import a single reference image  
- Automatically generate PBR textures  
- Create a ready-to-use textured plane in Unreal  

This brings the same **AI-assisted material workflow** used in Blender directly into Unreal production pipelines.
