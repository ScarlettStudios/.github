## 🚀 Latest Release

### PlaneToPBR — Blender Extension

Generate a **fully textured PBR plane from a single image in one click.**

PlaneToPBR automatically generates:

- Diffuse
- Normal
- Roughness
- Depth
- Segmentation mask

→ Built for **Blender 4.2+**
